---
name: Screenshot fidelity
description: How to adapt supplied visual references for RobotPay pages.
---

When the user provides a screenshot as a layout reference, preserve its overall composition, content order, and level of visual density. Adapt the copy and brand colors to RobotPay, but do not replace a simple reference layout with a generic hero or card grid unless the user asks for that change.

**Why:** The user corrected the contact page after it was redesigned into a large hero and card grid instead of following the compact contact-list layout in the reference.

**How to apply:** Before implementing a screenshot-based page, identify its layout structure and keep that structure recognizable. For contact pages, use the homepage header, a short notice, plain contact rows, generous white space, and RobotPay blue in place of the reference’s yellow.
